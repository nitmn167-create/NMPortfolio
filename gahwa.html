Project Overview

A creative concept developed at DXB LIVE, inspired by Emirati coffee culture. The project combines traditional elements with modern graphic and motion design.

02 / ABOUT THE EVENT

About the Event

An international championship planned for Abu Dhabi in March 2027, celebrating the tradition and skills of preparing and serving Emirati Gahwa.

03 / DESIGN CONCEPT

Design Concept

The goal was to create a modern visual identity while respecting Emirati culture, using a unique logo, colours, typography and event branding.
