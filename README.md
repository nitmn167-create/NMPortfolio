# Nitesh Mishra — Portfolio

A responsive, buildless portfolio website for Nitesh Mishra, Motion and Graphic Designer in Dubai.

## Files

- `index.html` — complete page, styles, and navigation JavaScript
- `assets/showreel.jpg` — YouTube showreel thumbnail

## Preview locally

Run `python3 -m http.server 8000` in this directory and open http://localhost:8000.

No dependencies, installation, or build step are required.

## Edit

Update the copy, links, and styling in `index.html`. Images are in `assets/`.

## Free hosting with GitHub Pages

In the repository's **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/ (root)**, and save. GitHub displays the published URL once deployment finishes.

## Content

Professional details and portfolio links were sourced from the owner's uploaded LinkedIn profile export. The hero uses original typographic artwork; a profile portrait can be added later.
